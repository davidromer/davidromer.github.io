## Contexto

JuriGest es un sistema de gestión legal que estoy construyendo desde cero para centralizar el trabajo diario de una firma de abogados.

## Tecnologías

- **Backend:** Django y Django REST Framework.
- **Base de datos:** PostgreSQL.
- **Frontend:** React.
- **Despliegue:** Docker.

## Qué busca resolver

- Gestión documental y seguimiento de casos legales.
- Automatización de procesos internos.
- API REST para conectar la interfaz web con otros sistemas.

En construcción. Publicaré avances y el repositorio cuando tenga una primera versión estable.
